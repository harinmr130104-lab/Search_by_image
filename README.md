# Поиск по скриншоту

Утилита для Windows ищет изображение в Google Lens по выделенной области экрана. В фоновом режиме выделение можно вызвать глобальным сочетанием **Ctrl + Print Screen (PrtSc)** из любого приложения.

## Установка

Нужны Python 3.13 и Google Chrome. Откройте PowerShell в папке проекта и выполните команды.

```powershell
py -3.13 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

## Горячая клавиша

### Включить

Запустите обработчик один раз за сеанс Windows. Он продолжит работать после закрытия PowerShell. После нового входа в Windows выполните команду снова.

```powershell
Start-Process -FilePath ".\.venv\Scripts\pythonw.exe" -ArgumentList ".\main.py", "--hotkey" -WorkingDirectory (Get-Location).Path -WindowStyle Hidden
```

### Использовать

1. Удерживая **Ctrl**, нажмите **Print Screen (PrtSc)**. Откроется окно выделения.
2. Обведите нужную область левой кнопкой мыши. Нажмите **Esc**, чтобы закрыть окно без отправки.
3. Отпустите кнопку мыши, чтобы отправить выделенный фрагмент в Google Lens. Проверьте результат в отдельном окне Chrome.

Повторное нажатие **Ctrl + Print Screen** во время выделения или передачи снимка пропускается. Если при включении появляется сообщение, что сочетание занято, проверьте, запущен ли обработчик. Если сочетание использует другое приложение, освободите его там.

### Остановить

```powershell
.\.venv\Scripts\python.exe .\main.py --stop-hotkey
```

Для запуска с сообщениями в консоли используйте `.\.venv\Scripts\python.exe .\main.py --hotkey`. Чтобы остановить такой обработчик, нажмите **Ctrl+C** в его консоли.

## Разовый запуск

Чтобы сразу открыть выделение, запустите скрипт без параметров.

```powershell
.\.venv\Scripts\python.exe .\main.py
```

## Как передаётся снимок

Программа формирует PNG выделенной области в памяти. Локальный сервер закрывается после передачи снимка в Chrome или по истечении восьми секунд. Затем Chrome отправляет фрагмент в Google Lens.

Окно Chrome открывается по центру монитора с фиксированным размером 800 × 640 при масштабе 100%. Размер учитывает масштаб Windows и доступную рабочую область монитора. Если Google запросит CAPTCHA, пройдите проверку в Chrome.

# Поиск по скриншоту

Утилита для Windows ищет изображение в Google Lens по выделенной области экрана.

## Запуск

Нужны Python 3.13 и Google Chrome. Из папки проекта выполните команды в PowerShell.

```powershell
py -3.13 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe .\main.py
```

## Как это работает

1. Выделите нужную область левой кнопкой мыши. Нажмите `Esc`, чтобы отменить выделение.
2. Программа передаёт выбранный фрагмент как PNG прямо из памяти и открывает результаты Google Lens в новой вкладке обычного Chrome.
3. Локальный сервер закрывается после передачи снимка или по истечении 8 секунд. Скриншот в файл не записывается.

Если Google запросит CAPTCHA, пройдите проверку в Chrome.
